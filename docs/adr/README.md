# アーキテクチャ決定記録（ADR）

ファイル名は`NNNN-short-title.md`とし、Status（Proposed / Accepted / Superseded）、
日付、背景、選択肢、決定、影響、関連Issue・PR・証跡のリンクを記載します。
Acceptedにする際はレビューでの決定を参照してください。
履歴を黙って書き換えず、新しい記録で以前の決定を置き換えます。
今回の初期整備では、製品アーキテクチャの決定は承認していません。
