# ADR 0019: 記憶の訂正・時間変化・矛盾・削除と失効

Status: Proposed

日付: 2026-10-06

## 背景

現行Coreは、会話履歴の削除・プライベートモード化による出典の撤回と、残る出典からの再構成を実装しています
（[ADR 0006](0006-conversation-memory-controls.md)、[ADR 0007](0007-memory-provenance-and-revocation.md)）。
一方、知識の訂正と時間変化の区別、矛盾の保留、管理操作による訂正・削除、依存する派生結果の失効は
ありません。[ADR 0015](0015-memory-model-reorganization.md)に従い、PoCの
[意味記憶の訂正・時間変化・矛盾](https://github.com/FYuki/digital-souls/blob/fce7382884d981c42be7fbd3ddaffe7469e27588/docs/decisions/semantic-memory-lifecycle-2026-09.md)と
[Episode・Fact・Semantic境界](https://github.com/FYuki/digital-souls/blob/fce7382884d981c42be7fbd3ddaffe7469e27588/docs/decisions/episode-fact-semantic-boundaries-2026-09.md)第9節を採用します。

## 決定

### 1. 知識の適用範囲

スレッドは増分抽出の枠に限ります。知識の照合・参照・訂正は、同じBinding全体へ適用します。
スレッドごとに知識を分離すると、別スレッドで訂正・想起できないためです。

### 2. 訂正と時間変化

- 明示的な訂正（「間違えた、実は〜」）は旧知識の訂正として追跡する。
- それ以外の食い違いは原則として時間変化とし、旧状態を履歴として保持する。
  適用日時が不明な場合は補完しない。
- 誕生日など通常変化しない属性の食い違いは矛盾として保留し、どちらも確定して断定しない。
- 自己申告と経験からの一般化が食い違う場合は共存させ、会話では自己申告を優先する。
  矛盾だけでは一般化を無効にしない。
- 未解決の矛盾は後続の内省から参照できるようにする。質問や主観の表出はこの範囲に含めない。

適用時期と保存時刻を区別し、訂正・時間変化・矛盾の関係を追跡します。

### 3. 管理操作

| 操作 | 範囲 | 扱い |
| --- | --- | --- |
| 本文の訂正 | ユーザー自己申告に由来するSemanticと、Fact単位 | 元発言を書き換えず、管理操作による訂正として根拠・版を追跡する |
| 削除 | すべての形成経路のSemantic、Episode、Fact | 元会話・Episodeの削除とは別の操作。同じ出典・版からの再生成を防ぎ、新しい根拠からの取得は許可する |

削除の再処理防止には、本文を残さない最小の識別情報だけを保持します。削除済み本文を監査目的で保持し続けません。
管理操作も正本の共通の保存・版・privacy・失効契約を通し、管理専用の正本を作りません。
候補ごとの手動承認や手動のFact統合は追加しません。

### 4. 失効（Invalidation）

根拠となるEpisode・Fact・source・統合関係の訂正・削除・版の失効時は、次を適用します。

- 依存する統合関係、Semantic、Reflection、派生結果を、正本上で即時に利用停止し、再評価の対象にする。
- 他の出典が残っていても、旧統合・旧本文を無条件に有効のままにしない。残る根拠から再評価する。
- 登録・参照更新・統合関係・派生index予定を原子的に整合させ、適用直前に版を検証する。
- 循環、複数の有効な統合先、別Bindingへの参照を拒否し、再試行・並行処理で二重に統合しない。
- 派生indexの削除・再生成が遅れても、取得時に正本で有効性を再確認する。
- 旧ID、統合履歴、別の参照、checkpointから、削除・無効化した情報を復活させない。
- 人格全体を無条件に過去へrollbackせず、影響する特性と残る根拠から再評価する（[ADR 0020](0020-reflection-personality-relationship.md)）。

### 5. Coreの操作仕様との関係

[ADR 0006](0006-conversation-memory-controls.md)のユーザー指定の操作仕様を優先します。

- 会話履歴の削除では、そこから作られた記憶も削除します（PoCの「履歴削除と記憶の物理削除は別操作」より厳しい）。
- スレッドのプライベートモード化では、そのスレッド由来の既存記憶を削除し、解除しても自動で復活させません。
- 複数sourceの記憶で一部のsourceが撤回された場合は、旧記憶を直ちに利用停止し、残る適格sourceから再構成します。
- アーカイブは記憶を維持します。

Episode・Fact・Semanticが加わっても、これらの操作は出典を共有するすべての記録と派生結果へ同じく適用します。
話を聞いた別のEpisodeまで無条件に物理削除はしませんが、削除対象の情報が本文に残る場合は停止・再評価します。

## 影響

- 正本に、訂正・時間変化・矛盾の関係、適用時期、削除の再処理防止の識別情報を追加します。
- 現行の撤回イベントとepoch（ADR 0007）を、Episode・Fact・Semantic・Reflectionへの依存にも拡張します。
